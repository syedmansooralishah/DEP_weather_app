# ⛅ DEN Weather App

DEN Weather App is a modern Flutter application that provides real-time weather updates for cities around the world. With an intuitive design and simple interface, it helps users check temperature, humidity, weather conditions, and more.

This application was developed as part of a **remote internship** with **Digital Empowerment Network**.

---

## 🚀 Features

* Real-time weather data
* Search weather by city name
* Displays temperature, humidity, and weather description
* Beautiful and responsive UI
* Location-based weather

---

## 📦 Tech Stack

* **Flutter** – UI Toolkit
* **Dart** – Programming Language
* **HTTP Package** – API communication
* **OpenWeatherMap API** – Weather data source (or another API depending on your code)

## 🛠️ Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/syedmansooralishah/DEN_weather_app.git
   cd DEN_weather_app
   ```

2. Install dependencies:

   ```bash
   flutter pub get
   ```

3. Run the app:

   ```bash
   flutter run
   ```

> Make sure you have the Flutter SDK installed and a valid API key for weather data if required.
